# GridTwin Command

Build a polished, production-quality web application called:

"GridTwin AI — Agentic Predictive Power Maintenance"

This is a simulation/demo platform for an academic final-year project titled:

"Agentic AI Framework for Predictive Power Grid Maintenance"

The application should demonstrate how Agentic AI, Digital Twins, sensor data, predictive analytics, and autonomous maintenance planning can work together for power-grid assets such as transformers and switchgears.

IMPORTANT:
This is NOT a generic CRUD dashboard.
It should look like a sophisticated industrial AI command center used by a power-grid operations team.

The application must work completely with MOCK DATA.
Do not require any external API, database, paid API, or API key for the initial demo.

Follow all sections, data schemas, visual themes, agentic workflows, simulation modes, digital twins, GIS mapping, and specifications detailed in the attached project specification document.
